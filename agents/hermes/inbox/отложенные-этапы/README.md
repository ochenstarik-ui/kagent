# Отложенные постановки

Здесь лежит **не сделанная** работа. Эти четыре постановки были написаны слишком крупными:
дважды упирались в бюджет итераций и ни разу не выполнялись. Их вынесли из очереди, но
предмет никуда не делся.

Перед выдачей каждую надо разрезать на узкие карточки по образцу пакетов P и E: один-два
файла, одна проверочная команда, один заход.

| Файл | Что осталось несделанным | Что уже закрыто из этого |
|---|---|---|
| `0.9.2-reproducibility.md` | реестр промптов, жизненный цикл контекста с якорями и компактификацией | кассеты и режимы live/record/replay сделаны в ADR-0026 |
| `0.9.3-verification-integrity.md` | заморозка тестов, разделение code diff и test diff, мутационная проверка, merge queue | ничего |
| `0.9.4-economics.md` | бюджетный ledger, автостоп по расходу, кэш модельных вызовов | ledger вынесен в `hermes-e12-budget-ledger.md`; ledger эффектов частично сделан в git-контуре |
| `0.9.5-boundaries.md` | контракт человеческого решения с TTL, исполняемые уроки, изоляция личного контура | ничего |

Соответствующие решения приняты и лежат в `docs/adr/`: ADR-0005, 0007, 0009, 0011, 0012,
0013, 0014, 0015. То есть архитектура описана, реализации нет.
