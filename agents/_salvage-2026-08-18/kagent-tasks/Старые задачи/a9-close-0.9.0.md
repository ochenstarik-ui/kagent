## 1. Вернуть HTTP-клиент gateway на hyper

В ходе задачи «починить сборку» исполнитель вышел за границы задания и заменил клиент:
удалил `hyper`, `hyper-util`, `axum-extra`, добавил `reqwest` с расщеплением по платформам.

```toml
[target.'cfg(not(target_os = "windows"))'.dependencies]
reqwest = { version = "0.12.5", default-features = false, features = ["rustls-tls"] }

[target.'cfg(target_os = "windows")'.dependencies]
reqwest = { version = "0.12.5", default-features = false, features = ["native-tls"] }
```

Почему это надо убрать:

- gateway проксирует обычный HTTP на внутренние сервисы, TLS-бэкенд ему не нужен вообще, и
  вся конструкция решает проблему, созданную самим переходом на `reqwest`;
- Linux и Windows собирают разный код. Расхождение уже проявилось: `cargo test` падал
  локально на отсутствии `dlltool.exe` из цепочки `native-tls` при зелёном прогоне в CI;
- зависимость добавлена без обоснования и без указания лицензии, что запрещено правилами
  репозитория;
- переписывание прокси меняет обработку заголовков, потоковую передачу и таймауты, и ничем
  не покрыто тестами.

Что сделать:

1. восстановить зависимости `hyper`, `hyper-util`, `http-body-util`, `axum-extra` в тех
   версиях, что в `main`: `git show origin/main:services/gateway/Cargo.toml`;
2. удалить обе секции `[target.'cfg(...)'.dependencies]` и `reqwest`;
3. вернуть проксирование на `hyper_util::client::legacy::Client`; исходную реализацию взять
   из `git show origin/main:services/gateway/src/main.rs`;
4. **сохранить всё, что исправлено в этой ветке**: корректный `get_request_id`, подключённый
   ограничитель частоты с фоновой очисткой, форматирование, отсутствие предупреждений
   clippy. Откатывается только замена клиента;
5. пересобрать `Cargo.lock`.

Если после отката всплывёт причина, по которой `hyper` в этой ветке не собирался, —
остановись и опиши её. Возможно, замена клиента была обходом настоящей проблемы, и решение
должно приниматься отдельно.

## 2. Доделать ограничитель частоты

Сейчас в `main.rs`:

```rust
let limiter = RateLimiter::new(60, 100);
```

Три недоделки против постановки:

- **параметры захардкожены.** Должны читаться из окружения:
  `GATEWAY_RATE_LIMIT_WINDOW_SECONDS` (по умолчанию 60) и
  `GATEWAY_RATE_LIMIT_MAX_REQUESTS` (по умолчанию 120). Значения по умолчанию — константы
  рядом с объявлением структуры, разбор с запасным значением при некорректном вводе;
- **нет заголовка `Retry-After`** в ответе `429`. Значение — остаток текущего окна в
  секундах;
- добавь обе переменные в `.env.example` в раздел портов и настроек gateway.
