## 0.9 — Trust and Economics Foundation

Реализация ADR-0004…ADR-0016. Порядок отражает зависимости: сначала зелёная сборка
и вычисляемый статус, затем воспроизводимость, затем целостность верификации,
затем экономика.

### 0.9.0 — Green trunk (предусловие)

- [ ] pnpm-lock.yaml в репозитории, node-job проходит
- [ ] gateway компилируется, `cargo fmt --check` и `clippy -D warnings` проходят
- [ ] control-plane стартует и работает на PostgreSQL, а не на in-memory store
- [ ] Python-job в CI: линт и тесты для сервисов

### 0.9.1 — Измеримость (ADR-0008, ADR-0016)

- [ ] Машиночитаемый реестр возможностей и доказательств
- [ ] Вычисляемый статус этапов из артефактов CI
- [ ] Spec drift check: недостижимый код, недокументированные маршруты, отсутствующие changelog и ADR
- [ ] Eval-suite платформы и метрики автономности

### 0.9.2 — Воспроизводимость (ADR-0004, ADR-0007, ADR-0012)

- [ ] Кассеты модельных вызовов и режимы live/record/replay
- [ ] Реестр промптов с версионированием
- [ ] Детерминированная сборка контекста, якоря и политика компактификации

### 0.9.3 — Целостность верификации (ADR-0005, ADR-0009)

- [ ] Разделение code diff и test diff, заморозка тестов
- [ ] Проверка запрещённых конструкций в test diff
- [ ] Мутационная проверка новых тестов
- [ ] Merge queue, защита trunk, политика конфликтов

### 0.9.4 — Экономика и эффекты (ADR-0006, ADR-0010, ADR-0013)

- [ ] Двухфазный бюджетный ledger, иерархия бюджетов
- [ ] Автостоп по burn rate и глобальная пауза
- [ ] Ledger внешних эффектов, outbox, процедуры сверки
- [ ] Кэш модельных вызовов и prefix-stable контекст

### 0.9.5 — Взаимодействие и границы (ADR-0011, ADR-0014, ADR-0015)

- [ ] Контракт человеческого решения с TTL и единой очередью
- [ ] Исполняемые уроки и вывод бесполезных guardrails из обращения
- [ ] Изоляция личного контура

## 0.10 — Runtime and Distribution

Реализация ADR-0017…ADR-0020 и разделов ТЗ 42–51.

### 0.10.0 — Песочница (предусловие)

- [ ] rootless container или microVM, отдельный UID, namespaces, seccomp, MAC
- [ ] read-only root, временный workspace, лимиты CPU/RAM/PID/disk
- [ ] scoped secrets и явные capability grants
- [ ] тесты выхода из песочницы в CI

Без этого раздел 42 не включается ни в одном режиме, включая локальную разработку.

### 0.10.1 — Программная среда агента (ADR-0017)

- [ ] единственный инструмент модели, постоянное ядро
- [ ] Typed Host Bridge: schema, capability grants, политика, audit до выполнения
- [ ] инвариант шима: без вызовов провайдеров и без agent loop внутри ядра
- [ ] лимит и TTL состояния ядра, инспекция из Run Timeline
- [ ] замена реестра ToolContract типизированными вызовами

### 0.10.2 — Сессия как дерево (ADR-0018)

- [ ] append-only типизированные записи, дерево, построение контекста обходом пути
- [ ] навигация, форк, сводка оставленной ветки
- [ ] атрибуция расхода субагента родителю
- [ ] авторитет в PostgreSQL и object storage, файл транскрипта как кэш

### 0.10.3 — Долгоживущие сессии

- [ ] резидентный worker: отключение клиента не останавливает задачу
- [ ] очередь сообщений, steering и follow-up, побочный вопрос вне контекста
- [ ] цели, heartbeat, расписания
- [ ] ограниченный автономный режим с обязательными условиями остановки
- [ ] восстановление после сбоя через сверку ledger эффектов

### 0.10.4 — Harness, навыки, расширения

- [ ] слои harness, неизменяемое ядро политики
- [ ] refinement на доказательствах через eval-suite, snapshots и откат
- [ ] навыки как пакеты, ленивая загрузка, уровни доверия
- [ ] поверхность расширений: события, регистрация инструментов и команд

### 0.10.5 — Приватность маршрутизации (ADR-0019)

- [ ] структурные декларации поставщиков: retention, обучение, регион
- [ ] ограничения класса приватности как условие отбора кандидатов
- [ ] запрет тихой деградации, запись удовлетворённых ограничений в audit
- [ ] негативные тесты: класс не достигает несоответствующего поставщика

### 0.10.6 — Распределённое исполнение (ADR-0020)

- [ ] Worker runtime, enrollment, lease, heartbeat
- [ ] Scheduler, пулы, размещение, повторы
- [ ] артефакты: адресация по содержимому, подписанный манифест, возобновляемая загрузка
- [ ] версионирование протокола, capability negotiation, тесты совместимости в обе стороны

### 0.10.7 — Инфраструктурный мост

Заблокировано: требует парных пунктов в плане Server Monitor Manager.

- [ ] файл и сокет обнаружения на стороне инфраструктурного слоя
- [ ] роль интеграции как частный случай automation identity
- [ ] типизированное действие установки Worker
- [ ] физическая приёмка управляемых Links
